Описание

Компания Tecsis (Германия), основанная в 1921 году, сегодня является известным мировым разработчиком и производителем датчиков и измерительных приборов для всех отраслей промышленности и научно-исследовательских изысканий.

Более 10 тысяч наименований изделий Tecsis сгруппированы в продуктовых линейках: «Сила», «Давление», «Температура», «Переключатели» и «Системные решения». Официальный сайт Tecsis не содержит справочную информацию на русском языке - только на английском и немецком.  

Компания уделяет огромное внимание применению инновационных технологий, процессов и материалов. Благодаря этому, манометры, тензодатчики, термометры Tecsis занимают достойное место на рынке измерительной техники и во многих случаях применяются в качестве эталонных в калибровочных центрах. Купить продукцию Tecsis в России с доставкой в любой регион удобно и выгодно в нашей компании "Система Снабжения".

Электрические датчики

Электрические датчики давления Tecsis находят применение в гидравлических и пневматических системах практически всех отраслей промышленности

Датчики общего назначения

Вощможны различные варианты включения в процесс, электрические соединения и все международные стандарты выходного сигнала. Их точность, надежность, устойчивость к коррозии и механическим нагрузкам делает их пригодными для решения всех задач измерения – в производстве, разработке или в лаборатории.

Датчики специального назначения

  • с фронтальной мембраной;
  • для мобильной гидравлики;
  • для высоких давлений;
  • искро-защищенного исполнения Ех;
  • погружной зонд для измерения гидростатического уровня жидкостей;
  • высокого разрешения ( для калибровочных установок);
  • компактного исполнения;
  • для холодильной техники;
  • стандарта CANopen®;
  • с дисплеем.

Датчики дифференциального давления

Это преобразователи с отличными техническими характеристиками (долгосрочная стабильность, устойчивость при пиковых значениях, коррозионная и механическая стойкость), пригодные для решения самых сложных задач измерения.

Манометры Tecsis

Механические датчики (манометры Tecsis) – это манометры (с трубкой Бурдона, диафрагменные или с капсульной пружиной), различных размеров и вариантов присоединения, предназначенные для жидких и газообразных сред.

Для измерения относительного давления выделяют:

  • стандартные;
  • для тяжелых условий эксплуатации;
  • специального назначения (для дайвинга);
  • специального антикоррозионного исполнения;
  • для высоких показателей;
  • высокого разрешения.

Для измерения абсолютного давления – с диафрагмой, предназначены для применения в химической промышленности. Выполнены из материалов, стойких к химически агрессивным жидкостям и другим средам.

Для измерения дифференциального давления – это манометры всех известных принципов (с трубкой Бурдона, диафрагменные, с пружиной и т.д.). Выпускаются в стандартном и антикоррозионном исполнениях.

Мехатронные датчики Tecsis

Мехатронные манометры для измерения относительного давления:

  • стандартные;
  • для тяжелых условий эксплуатации;
  • специального антикоррозионного исполнения;
  • для сверхвысоких показателей.

Мехатронные манометры для измерения дифференциального давления:

  • специального антикоррозионного исполнения.
