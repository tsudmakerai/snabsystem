# Полная копия сайта «Система Снабжения» (snabsystem.ru)

Полнофункциональная, адаптивная и автономная копия сайта поставщика промышленного оборудования **«Система Снабжения»** (`https://snabsystem.ru/`).

## Возможности и структура
- **Главная страница**:
  - Полная шапка с контактами (Москва, Россия), логотипом и вызовом обратного звонка.
  - Интерактивный промо-слайдер (3 слайда с логотипами брендов и переключателями).
  - Сетка категорий каталога со спрайтовыми иконками (`icon-term-492`, `icon-term-3` и др.).
  - Блоки «Почему мы?» и «Для каждого клиента» с оригинальными иллюстрациями.
  - Подвал с отзывами клиентов (ООО "РосКаз", ООО "Химмашторг", ООО "ДорСтрой", ПАО ПБК "КРЫМ") и реквизитами.
- **Динамические AJAX-панели навигации**:
  - *Продукция* — каталог со всеми 6 основными направлениями и подкатегориями.
  - *Производители* — алфавитный указатель брендов (A-Z) и быстрый поиск.
  - *Контакты* — реквизиты, телефоны и форма быстрой связи с менеджером.
  - *Информация* — условия оплаты, доставки, гарантии и юридические документы.
- **Каталог и бренды**:
  - Страницы всех разделов (`/catalog/promyshlennoe-oborudovanie`, `/catalog/elektrodvigateli`, `/catalog/gidravlika`, `/catalog/nasosy` и др.).
  - Реестр производителей (`/brands`) с фильтрацией по алфавиту.
  - Страницы брендов (`/brand/siemens`, `/brand/cantoni`, `/brand/festo` и др.) с формой запроса КП.
- **Интерактивные виджеты**:
  - Живой поиск по каталогу и производителям с автодополнением.
  - Модальное окно «Обратный звонок».
  - Модальное окно «Запрос стоимости / КП».
  - Всплывающие уведомления (Toast).
- **Юридические и информационные страницы**:
  - «О компании» (`/about`).
  - «Политика конфиденциальности» (`/policy`).
  - «Публичная оферта» (`/public_offer`).
  - «Контакты» (`/contacts`).
- **Автономность**:
  - Более 660 графических файлов (логотипы брендов, иконки, баннеры) хранятся локально в `public/assets/images/`.

## Запуск проекта

### Вариант 1: С помощью Node.js
```bash
node server.js
```
После запуска откройте в браузере: [http://localhost:3000](http://localhost:3000)

### Вариант 2: С помощью Python
```bash
python -m http.server 3000 --directory public
```
